# Практическая работа №3

## Цель

Посмотреть, как числа и текст хранятся в памяти в виде байтов.

## 1. Представление числа в байтах

| int   | Байты       |
| ----: | ----------- |
| 1     | 01-00-00-00 |
| 256   | 00-01-00-00 |
| 65536 | 00-00-01-00 |

int занимает 4 байта, поэтому у единицы остальные байты просто нули. Когда число больше 255, оно уже не влезает в один байт и появляется единица в следующем.

## 2. Порядок байтов

- IsLittleEndian: True
- Число: 305419896
- Hex: 0x12345678
- Байты: 78-56-34-12

Байты идут с конца, сначала младший. Само число не меняется, меняется только порядок хранения.

## 3. Текст и UTF-8

| Строка   | Символов | Байтов |
| -------- | -------: | -----: |
| `ABC`    | 3        | 3      |
| `Привет` | 6        | 12     |

Английские буквы занимают 1 байт, русские 2, поэтому байтов получилось больше, чем символов.

## 4. Английская и русская буква

| Символ          | UTF-8 |
| --------------- | ----- |
| `A` (латиница)  | 41    |
| `А` (кириллица) | D0-90 |

Буквы выглядят одинаково, но это разные символы, и байтов у них разное количество.

## 5. Обратное преобразование

- `Привет` в байты и обратно: получилось `Привет`.
- `123456789` в байты `15-CD-5B-07` и обратно: получилось `123456789`.

## Контрольные вопросы

1. **Что такое байт?** Это единица данных  из 8 бит, может быть от 0 до 255.
2. **Почему int занимает несколько байтов?** В один байт большое число не влезет, поэтому int хранится в 4 байтах.
3. **Что показывает GetBytes()?** Из каких байтов состоит значение в памяти.
4. **Что означает IsLittleEndian?** Что первым хранится младший байт числа.
5. **Почему порядок отличается от обычной записи?** Мы пишем число с большей цифры, а процессор хранит с младшего байта.
6. **Почему символов и байтов может быть разное количество?** Потому  что в UTF-8 русская  буква занимает 2 байта, а английская 1.
7. **Что делает Encoding.UTF8.GetBytes()?** Превращает строку в набор байтов в кодировке UTF-8.
8. **Зачем нужен GetString()?** Чтобы вернуть байты в текст, нужно указать ту же кодировку.
9. **Почему одни байты читаются по-разному?** Сами байты ничего не значат, смысл зависит от того, как программа их читает.
10. **Чем число отличается от текста в памяти?** Число хранится как двоичное значение, а текст как коды символов по кодировке.

## Итоговый  вывод

И числа, и текст хранятся в памяти как байты. int занимает 4 байта и хранится в порядке little-endian, а текст превращается в байты по кодировке, например UTF-8. Сами байты не говорят, что они значат. Например, 48-65-6C-6C-6F будет словом Hello, только если знать, что это UTF-8. Поэтому нужны правила, по которым байты читаются.
